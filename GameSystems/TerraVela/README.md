# Terra Vela

> 하늘을 떠다니는 **섬을 조각하고, 그 위에 짓고, 섬째로 조종해** 여행하는 협동 샌드박스
> Unity 6 (URP) · C#

![Terra Vela](https://github.com/user-attachments/assets/d1ebb687-5da3-4d4e-aea7-2df59ae9b89a)
<!-- 대표 장면: 섬 조각 → 건축 (조종·협동은 미구현) -->

내 섬이 곧 집이자 탈것이다. 남의 섬에 얹혀사는 게 아니라, **내가 만든 땅을 몰고** 하늘의 목적지로 간다 — 짓고 꾸미던 거점이 그대로 이동 수단이 되는 게 이 게임의 핵심 재미다.

이 저장소는 그 시스템들을 만들며 내린 **설계 판단**의 기록이다. 각 시스템 문서는 *무엇을 만들었나*보다 *왜 그렇게 나눴나*에 집중한다.

---

## 시스템

문서가 있는 시스템은 링크가, 아직인 것은 상태만 표시된다. 저장소는 시스템 문서가 하나씩 쌓이며 자란다.

### 핵심 루프 — 섬
| 시스템 | 내용 | 상태 |
|---|---|---|
| **[지형 · 건축](./IslandBuild/README.md)** | 마칭 스퀘어 섬 조각 + 모듈러 건축·지지·연쇄파괴 | ✅ 구현 + 리팩터 · 문서화 |
| 섬 조종 (helm) | 섬을 탈것으로 실시간 이동 · 관성 · 충돌 | 🔜 계획 |

### 캐릭터
| 시스템 | 내용 | 상태 |
|---|---|---|
| 이동 | Rigidbody + 상태머신 (기본 이동) | ✅ 기본 구현 |
| 이동 확장 | 활공 · 파쿠르 · 갈고리 통합 | 🔜 계획 |

### 월드 · 인프라
| 시스템 | 내용 | 상태 |
|---|---|---|
| 부팅 흐름 | 씬 전환 파이프라인 (additive 스왑, 영속 Core) | ✅ 구현 |
| 세이브 | 로컬 JSON (+ 클라우드 동기 전제) | ✅ 구현 |
| 멀티플레이어 | 협동 세션 · 세션 브로커 | 🔜 계획 |

> 시스템 문서를 새로 쓰면 해당 그룹에 행 하나를 추가한다. 새 카테고리가 필요하면 그룹을 늘린다.
